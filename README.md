# Everyday Lens

Create a complete working website called Everyday Lens.

The idea is simple: a user uploads a photo of any everyday object, and the website identifies it and explains what is visible on it, what the text means, and how the object is generally used.

Examples: debit card, credit card, medicine box, product package, bill, ticket, appliance label, document, or any other everyday object.

Build everything at once:

Modern responsive homepage

Everyday Lens logo and tagline: "Understand What You See."

Image upload and drag-and-drop

Camera/photo option

Image preview

Analyze button

AI/OCR analysis

Object identification

Extract and display text from the image

Explain important text, numbers, symbols, labels and sections in simple language

Explain how the object is normally used

Show important instructions and warnings

Clear results page with attractive cards

Loading animation while analyzing

History page for previous scans

About page

Navigation bar and footer

Mobile-friendly design

Privacy warning for sensitive information such as card numbers, CVV, PINs, OTPs and passwords

Do not include banking transactions, payments or financial account functionality

Use React, TypeScript and Tailwind CSS.

Make the application fully functional and connected from upload → image analysis → text extraction → explanation → results.

If an AI/OCR API is not available, create a working mock analysis system so the complete website can still be tested. Keep the AI/OCR integration easy to connect later.

Do not make this only a bill scanner. The main purpose is to understand any everyday object from an uploaded image.

Make the complete project polished and suitable for a college hackathon demonstration.
